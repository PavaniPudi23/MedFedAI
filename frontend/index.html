ONE SHARED DESIGN

Multiple local model copies

Hospital 1, Clinic 2, and Center 3 each start a local Deep CapsNet from the current global weights. They train separately on their own images; their local weights can differ after training.

SERVER UPDATE

One updated global model

FedAvg combines the local changes into one global model. That updated global model is broadcast to clients at the next round. Raw image files are not sent to the server.

CLASSIFICATION MODEL

Deep Capsule Network

The prototype uses the same compact Deep CapsNet design at each client and at the global server. The clients hold separate model weights during local training.

ALGORITHM USED IN THE CODE

Per federated round

  1. Send current global model weights to selected clients.
  2. Train one local copy on each client’s local images.
  3. Calculate each client’s weighted model change.
  4. Clip each weighted change to maximum L2 norm C.
  5. Add Gaussian noise: N(0, (σC)² I) to the clipped sum.
  6. Apply the protected update and save the new global weights.
  7. Update the Opacus privacy accountant for ε and δ.
Clipping
Δ̃k = Δk × min(1, C / ‖Δk‖₂)

Noisy update sum
Σ Δ̃k + N(0, (σC)² I)
This is central client-level DP. The local server sees client updates before adding noise; it is not patient-level privacy or a cybersecurity guarantee.

PRIVACY IN THIS PROTOTYPE

Client-level differential privacy

The code clips each client’s weighted model update and adds Gaussian noise to the update sum before changing the global model. The Opacus accountant records epsilon and delta.

The local aggregation server sees individual updates before noise is added. The guarantee protects a whole simulated client under stated assumptions; it is not patient-level privacy. Do not use this prototype for medical decisions.
